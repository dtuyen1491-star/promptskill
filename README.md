# SPINE-8 Video Prompting

Reusable Manus skill for writing, testing, debugging, and selecting AI video prompts.

## Included

- `spine-8-video-prompting.skill` — installable skill package.
- `SKILL.md` — core workflow.
- `references/` — prompt templates, bilingual lexicon, testing and selection, and Seedance/camera/emotion modules.

## Core method

SPINE-8 integrates:

- **S — Story intent**
- **P — Picture & identity**
- **I — Interaction + Performance**
- **N — Navigation + Camera path**
- **E — Events + Timeline**
- **8 — Bridge → Continuity → Style → Test → Generate → Select → Edit → Rewrite**

The package supports text-to-video, image-to-video, multishot prompting, performance direction, camera path design, multimodal asset binding, timeline prompting, scoped revision, bilingual English–Vietnamese output, and mechanical testing.

## Installation

Download `spine-8-video-prompting.skill` and add it to Manus Skills, or inspect the source files directly.
